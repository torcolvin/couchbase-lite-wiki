## Query API

### SQL

```sql
SELECT *
FROM  accounts
WHERE type = 'account' AND owner = 'John'
ORDER BY accountSize
```

### JAVA

```java
Query query = Query
    .select()
    .from(QueryDataSource.database(database).as("accounts"))
    .where(QueryExpression.property("type").equalTo("account").and(
           QueryExpression.property("owner").equalTo("John")))
    .orderBy(QueryExpression.property("accountSize"));
```
