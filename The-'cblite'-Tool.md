`cblite` is a command-line tool for inspecting and querying LiteCore and Couchbase Lite databases.

It now has [its own Github repo](https://github.com/couchbaselabs/cblite), where you can learn how to [build](https://github.com/couchbaselabs/cblite/blob/master/BUILDING.md) and [use](https://github.com/couchbaselabs/cblite/blob/master/Documentation.md) it.
