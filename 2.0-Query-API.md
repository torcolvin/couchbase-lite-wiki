##Query API

###SQL

SELECT * FROM accounts WHERE (type = 'account' AND account.owner = 'John') ORDER BY 'dealSize'

###JAVA

query .select() .from(database) .where( Expression.property("type").equalTo("account") .and(Expression.property("owner").equalTo("Wayne"))) .orderBy(Expression.property("dealSize"))

###iOS

```objective-c
[Query select: [CBLQueryResult all]
         from: [CBLQueryDatasource database: database]
        where: [CBLQueryExpression group: @[
                   [[CBLQueryExpression property: @"type"] equalTo: @"account"],
                   [[CBLQueryExpression property: @"owner"] equalTo: @"John"]
               ]]
      orderBy: [CBLQueryExpression property: @"dealSize"]
];
