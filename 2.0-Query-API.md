##Query API

###SQL

SELECT * FROM accounts WHERE (type = 'account' AND account.owner = 'Wayne') ORDER BY 'dealSize'

###JAVA

query .select() .from(database) .where( Expression.property("type").equalTo("account") .and(Expression.property("owner").equalTo("Wayne"))) .orderBy(Expression.property("dealSize"))
