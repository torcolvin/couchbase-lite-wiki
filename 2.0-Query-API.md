##Query API

###SQL

```sql
SELECT *
FROM  accounts
WHERE (type = 'account' AND account.owner = 'John')
ORDER BY dealSize
```

###JAVA

```java
Query query = Query
    .select()
    .from(QueryDatasource.database(database))
    .where(
        QueryExpression.group(
            QueryExpression.property("type").equalTo("account"),
            QueryExpression.property("owner").equalTo("John")
        ))
    .orderBy(QueryExpression.property("dealSize"));
```
